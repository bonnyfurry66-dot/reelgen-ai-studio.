Backend connection

Set API.base to your HTTPS backend. Required routes: POST /api/auth/register, POST /api/auth/login, GET /api/auth/me, POST /api/auth/logout, POST /api/story, GET/POST /api/videos and GET /api/videos/:id. The server must connect the AI story, video and speech providers, store videos in cloud object storage, and implement library deletion. Keep provider API keys server-side only.
